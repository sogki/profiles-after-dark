# Nocturne Foundry

Standalone dev-portal app inside the monorepo.

## Run locally

```bash
cd nocturne-foundry
npm install
npm run dev
```

Default local URL: `http://localhost:4177`

## Purpose

- Separate look-and-feel from the main Profiles After Dark website
- Landing page for internal dev projects
- Launchpad for Discord setup dashboard and future marketplace tooling
